# Video-Chaptering-using-Python
**Video Chaptering using Python
YouTube Transcript Extractor
A Python tool to extract transcripts from YouTube videos and save them as CSV files for further analysis.
Features

📹 Extract transcripts from any YouTube video with captions
💾 Save transcripts to CSV format with timestamps
📊 Includes video metadata (title, duration, timestamps)
🔍 Easy to analyze and search through video content
📈 Perfect for content analysis, research, and data visualization**
